# AWS Certified DevOps Engineer - Professional  (DOP-C02) 

This repository contains study notes for the AWS Certified DevOps Engineer - Professional certification. The content is curated directly from the official AWS Skill Builder exam preparation courses and learning plans.

The following table lists the main content domains and their weightings.

| Domain | % of Exam |
|--------|-----------| 
| [Domain 1](./Domain-1/): SDLC Automation | 22% |
| [Domain 2](./Domain-2/): Configuration Management and IaC | 17% | 
| [Domain 3](./Domain-3/): Resilient Cloud Solutions | 15% |
| [Domain 4](./Domain-4/): Monitoring and Logging | 15% |
| [Domain 5](./Domain-5/): Incident and Event Response | 14% | 
| [Domain 6](./Domain-6/): Security and Compliance | 17% |
| TOTAL | 100% |
